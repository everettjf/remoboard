# Remoboard screenshot sources

The first slide shows the current app's `Received Text` sheet. Its content is an example injected only in a DEBUG simulator build with `-storeScreenshotReceived`, using the same view that displays text sent from the browser to the app. It does not demonstrate a live device pairing session. The second slide uses the actual app home and PIN setup guidance. The third shows the real Quick Words view with the app's built-in default phrases, opened in DEBUG with `-storeScreenshotQuickWords`.

A physical iPhone capture of the keyboard extension paired with the computer browser remains the best additional proof for the main live-typing claim. Do not depict a completed live session using these simulator captures alone.
